# dotdash

A [morzer](https://github.com/morzecrew/morzer) bundle that runs an Xray gateway
behind Caddy and Cloudflare on a single Docker host, with a DNS-based entry point
alongside it and all outbound traffic routed through an upstream proxy you
provide.

> Requires `ghcr.io/morzecrew/xray` ([platform-images#125](https://github.com/morzecrew/platform-images/issues/125)).

## Install

Requires a domain on Cloudflare (free plan is enough), a Linux host with Docker
≥ 28 and Compose ≥ 2.35, `sops`, `age`, morzer ≥ 0.12.0, and upstream proxy
credentials.
`example.com` below is the proxied name, `t.example.com` the tunnel zone.

**1. Cloudflare**

- DNS: `example.com` A → server IP, **proxied**. SSL/TLS mode **Full (strict)**. Network → **gRPC on**.
- SSL/TLS → Origin Server → **Create Certificate** (ECC, 15 years); save `origin.pem` and `origin.key`.
- Authenticated Origin Pulls: run `scripts/cf-aop-cert.sh ./aop`, upload
  `aop/aop-client.crt` + `.key` under **Zone-level**, and switch AOP on
  **before** the first deploy. Keep `aop/aop-ca.key` offline.

**2. Tunnel delegation** (DNS only, not proxied; this publishes the server IP,
use a second IP with `xdns_bind` if that matters)

```text
ns.example.com.  A   <server IP>
t.example.com.   NS  ns.example.com.
```

**3. Server**: open 443/tcp and 53/udp. If `systemd-resolved` holds port 53,
set `xdns_bind` to the public IP.

**4. Deploy**

```sh
morzer secret recipients generate-recovery-key ~/dotdash-recovery.key   # store off the machine
morzer init --release <bundle> --domain example.com --recovery-recipient age1…

morzer config set upstream_host=proxy.provider.example
morzer config set upstream_port=1080
morzer config set upstream_protocol=socks          # or http
morzer config set xdns_domain=t.example.com

morzer secret set upstream_username
morzer secret set upstream_password
morzer secret set origin_cert < origin.pem
morzer secret set origin_key  < origin.key
morzer secret set cf_aop_ca   < aop/aop-ca.crt

morzer apply
```

The client id, path and encryption keys are generated by morzer. `apply`
succeeds only once Xray has fetched a URL through the upstream proxy and the
origin has refused a TLS client without Cloudflare's certificate.

**5. Clients**

```sh
morzer task run client-config --output
```

Prints a `vless://` link for XHTTP (v2rayN, v2rayNG, Hiddify, Happ, Streisand)
and an Xray outbound for XDNS. Treat the output as a password.

## Parameters

| Name | Default | |
| --- | --- | --- |
| `upstream_protocol` | `socks` | `socks` or `http` |
| `upstream_host`, `upstream_port` | required | upstream proxy |
| `upstream_udp` | `false` | relay UDP via a SOCKS5 upstream with UDP ASSOCIATE; otherwise UDP is dropped |
| `xdns_domain` | required | delegated tunnel zone |
| `xdns_bind` | `0.0.0.0` | host address for UDP/53 |
| `xdns_mtu` | `900` | tunnel reply size; lower if replies get lost |
| `https_port` | `443` | host port for Caddy |
| `log_level` | `warning` | Xray error log; access log is always off |
| `healthcheck_url` | `https://www.gstatic.com/generate_204` | fetched through the upstream by the healthcheck |

Check a change with `morzer release verify ./bundle --render-check`.
