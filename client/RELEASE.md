# dotdash-client

Not released yet. The first release comes with the next dotdash release, from
the same tag.

### Added

- A dotdash client for a machine or a network: mihomo with one SOCKS5 and HTTP proxy port that goes out through dotdash over whichever link of the device's subscription answers fastest, with rules that refuse destinations or send them directly. Published beyond the machine, the port asks for a password.
